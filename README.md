# 🌐 serversConnect

> Skrip otomatisasi instalasi satu baris (*one-liner*) untuk menghubungkan perangkat klien (Laptop, PC, Dev Machine) ke jaringan privat homelab via Tailscale mesh VPN dan Mosh.

Solusi koneksi remote super cepat tanpa lag ketikan (*zero typing delay*), melewati pembatasan ISP, dan tanpa bergantung pada rute *Cloudflare Tunnel* yang memutar.

---
